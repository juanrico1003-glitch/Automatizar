# Automatización Cuentas por Pagar (CXP)

Herramienta para organizar y estructurar reportes de Cuentas por Pagar en Excel de forma 100% automática.

---

## 🚀 Forma 1: La Más Fácil (Solo Clics - Sin Instalar Nada)

En esta carpeta ya tienes incluido el archivo ejecutable **`Organizador_CXP.exe`**:

1. Copia o coloca tus archivos Excel (`.xlsx` o `.xlsm`) en esta misma carpeta (o arrastra el archivo directamente encima del `.exe`).
2. Haz **doble clic** sobre **`Organizador_CXP.exe`**.
3. El programa organizará el archivo automáticamente y te mostrará el resumen en pantalla.

> **Nota:** ¡No requiere que la PC tenga Python instalado! Funciona en cualquier Windows 10 u 11.

---

## 🛠️ Forma 2: Con Python y Scripts .BAT

Si deseas ejecutarlo mediante el entorno de Python:

1. **Instalación (solo se hace una vez por PC):**
   - Haz doble clic en **`instalar_requisitos.bat`**.
   - El instalador detectará Python automáticamente, configurará el entorno virtual y las librerías necesarias.
   - Al final te preguntará si deseas crear un acceso directo en tu Escritorio.

2. **Ejecución diaria:**
   - Haz doble clic en **`ejecutar_automatizacion.bat`**.
   - O usa el acceso directo que se creó en tu Escritorio (**`Organizador CXP`**).

---

## 📌 Crear Acceso Directo en el Escritorio
Puedes hacer doble clic en cualquier momento sobre **`Crear_Acceso_Directo.bat`** y se creará un acceso directo en tu Escritorio de Windows para acceder a la automatización con un solo clic.
